# Journal de travail — 13 novembre 2026

## Contexte

Ajout de la fonctionnalité de requête de visibilité `getSensorsSeeing` sur le `SensorSystem`. Réponses aux questions de cadrage :

- Sémantique : ligne de visée libre (le senseur voit la cible si le rayon origine→cible n'est pas occulté, même si la cible n'est pas entièrement dans le volume).
- Distance : distance le long du rayon jusqu'à l'intersection avec la surface du volume.
- Entrée : tout objet avec position (Entity, Primitive, Cartesian3).
- API : asynchrone (Promise).
- Partie occultée : option configurable `includeOccludedVolume` (défaut false).
- Exposition : SensorSystem uniquement.
